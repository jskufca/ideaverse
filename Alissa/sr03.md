# Revision Request SR-03: Documenting the Simulation Study

The ABM itself is carefully documented in Chapter 5, including its state variables, scheduling, parameters, initialization, inputs, and code. This revision is not asking you to repeat that material. Instead, I would like to make the experimental protocol easier for a reader to locate and apply across the simulation studies in Chapters 5 and 7. In particular, please make clear which summary procedure, number of independent runs, parameter values, and averaging steps apply to each reported set of figures.

## What to add

Please add a short “Simulation Protocol” subsection, or a compact table, that states:

- The number of independent simulation runs used for each configuration or parameter
  combination
- How random initial conditions and random seeds were handled
- How long each simulation was run
- How much of each simulation was discarded as transient or burn-in
- Over what time interval the reported outputs were averaged
- Whether the reported values are time averages, spatial averages, averages across
  simulations, or some combination of these
- What one blue point represents in the identity plots
- How the red means, confidence intervals, and error ellipses were calculated
- Which parameter values were varied and which were held fixed in each experiment

You do not need to add a great deal of prose. A short table, followed by a paragraph
explaining the main averaging procedure, would probably be the clearest approach.

## Chapter 5

Please make the procedure used in Sections 5.2 and 5.3 explicit. For example, the
current text explains that the first 4,500 time steps are discarded and the next 2,500
are averaged. Please make it clear whether that procedure is used throughout the ABM
experiments and how many independent simulations contribute to each figure.

## Chapter 7

Please add a corresponding description of the parametric-study design. In particular,
give the exact values used for each parameter grid, the number of ABM simulations at
each grid point, and any computational limitations that affected the number of runs.

Where the current text says that only “a few simulations” could be run, please replace
that with the actual number. If a pattern is unclear because of limited simulations,
it is fine to say so directly; that is more helpful to the reader than trying to make
the plot say more than it can.

## Goal

The goal is simply that a reader can understand the experiment, interpret the figures,
and reproduce the analysis without having to reconstruct the procedure from the code
or from scattered comments in the text.

Please make these revisions directly in Overleaf and leave a comment at the beginning
of the new or revised protocol subsection noting `SR-03 complete`.
