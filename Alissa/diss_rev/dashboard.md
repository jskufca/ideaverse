## Review principles

- The model uses analytical verification and purpose-relative qualitative validation.
- Qualitative agreement with external empirical patterns supports the model’s intended theoretical use.
- The dissertation does not claim city-specific predictive calibration.
- Parameter choices identify reasonable, literature-informed ranges for study unless explicitly calibrated otherwise.
- Existing spatial experiments should be interpreted as comparisons of specified modeled configurations.
- Student owns substantive explanation, interpretation, and mathematical-methodological confirmation.
- Advisor owns local copyediting, terminology, captions, cross-references, formatting, and final integration.

### Collaboration rules

- Work in different sections whenever possible.
- Do not edit the same paragraph concurrently.
- Use Overleaf comments for questions and decisions.
- Use Track Changes if available; otherwise, place a brief comment at the beginning of a revised section, such as `SR-01 complete`.
- Create a dated project copy or tag before beginning substantial changes.
